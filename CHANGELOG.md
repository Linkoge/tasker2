# Changelog

- 1.8: Save moved from the bottom of the New/Edit task and +++ screens into the top-right of the header, so it stays visible with the keyboard open (the bottom Save/Cancel buttons are gone). New defaults: crossed-out style "Faded color" and cross-out line thickness 1 dp (saved choices are kept).
- 1.7: Long-press a category tab (or tap the already selected one) for a menu: Move left / Move right, Rename, Delete (Delete always asks for confirmation and says how many tasks go with it). A plain "+" pinned at the right end of the tab row adds a category (added last and selected). New Settings: cross-out line thickness (1–6 dp in 0.5 steps, default 2) and "Crossed-out tasks: Gray / Faded color" (Faded keeps a heavily washed-out hint of the priority color on the badge, bar, line and checkbox). Both are saved and included in Reset to defaults.
- 1.6: "Gap between tasks" now runs from −16 to +16 dp with 0 (the old look) in the middle; negative values tighten rows (list spacing, then row padding, then touch targets 48→40dp) and can never make rows overlap or clip. Saved 1.5 values keep working (values above 16 clamp to 16). The title is always vertically centered with the circle, priority badge/bar and checkbox; notes hang below it. A crossed-out task now has one continuous gray line from the left edge of the circle to the right edge of the checkbox. Notes text is smaller (0.75× the list font).
- 1.5: Crossed-out tasks are now completely gray: title, strike line, priority number and bar, both checkboxes. New Settings: "Gap between tasks" slider (0–24 dp), and separate "Show priority number" and "Show priority bar" switches. All are saved and included in Reset to defaults.
- 1.4: Typing in the +++ screen no longer hides the title list; Enter moves to the next title. Category tabs are spaced wider (6 spaces). New Settings screen (⋮ → Settings) with tab font size, task list font size and tab gap, plus Reset to defaults. New tasks start with no priority (None option in the selector; no number or bar shown; prioritized tasks sort first). Crossed-out tasks have a thicker line and keep a dimmed priority color. Each task row has a square checkbox on the right to cross out; the round circle on the left completes the task (long-press on the circle no longer crosses out).
- 1.3: The +++ button opens a screen to add many tasks at once. The app menu shows the version.
- 1.2: Category tabs no longer flash when pressed, and the Completed header is just an arrow.
- 1.1: Orange theme and more compact category tabs.
- 1.0: Basic app with categories, task priorities and moving tasks.
